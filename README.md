# SCAPS-1-D-simulation-on-melanin-based-solar-cells
SCAPS-1D simulation files, parameters, and datasets for melanin-based  solar cells.
## How to Use
1. Download and install SCAPS-1D (free from University of Ghent)
2. Load the .scaps parameter files from /parameters
3. Run simulations to reproduce results from the paper

## Key Results
- Optimized PCE: 4.80%
- Melanin layer thickness: [0.050nm]
- Best performing architecture: [Sequential optimisation of the hole transport layer, electron transport layer, and melanin absorber thicknesses yielded optimal values of 0.550 μm, 0.020 μm, and 0.050 μm respectively, producing an optimised device with a Voc of 1.0941 V, Jsc of 9.0162 mAcm⁻², Fill Factor of 48.69% and PCE of 4.80%. ]
